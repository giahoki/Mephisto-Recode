# Firefox

Распакуйте `build/firefox/Mephisto-Program.zip` и запустите `Mephisto.exe`. В Firefox 140+ откройте `about:debugging#/runtime/this-firefox`, нажмите «Загрузить временное дополнение» и выберите отдельный файл `build/firefox/Mephisto-Firefox-addon.xpi`. Отключите старую копию аддона, разрешите доступ к нужным шахматным сайтам и обновите вкладку с доской.

XPI в архиве не подписан: обычный Firefox не установит его как постоянное дополнение. Временная установка действует до перезапуска Firefox. Для постоянной установки нужна подпись Mozilla; батник не публикует и не подписывает аддон.

Аддон передаёт адрес/заголовок шахматной страницы и состояние доски только локальному приложению на `127.0.0.1:17864`. Доступ к содержимому страниц и адресам указан в Firefox-манифесте. Внешним серверам эти данные не отправляются.

Сборка из исходников: `build.bat` в корне проекта, затем выберите Firefox. Нужны Visual Studio C++ Build Tools (v143 в VS 2022 либо v145 в VS 2026), Windows SDK 10.0.26100.0 и доступ к NuGet при первой сборке. Результат: два файла в `build/firefox`: `Mephisto-Program.zip` и `Mephisto-Firefox-addon.xpi`. Батник работает из любой текущей папки. Без меню и паузы: `build.bat firefox --no-pause`.

Интерфейс приложения — WinUI 3 / C++/WinRT. DLL и ресурсы рядом с EXE входят в самодостаточный комплект: распаковывайте архив полностью.
